# Arcadia Resources

This directory contains the Arcadia SysML v2 library resources used at runtime by Capella for SysON.

The files are bundled directly so that the application does not depend on non-public package infrastructure at build time.

The resource contents are distributed under EPL-2.0. The library JSON embeds its original copyright statement for Obeo and Thales Global Services.
