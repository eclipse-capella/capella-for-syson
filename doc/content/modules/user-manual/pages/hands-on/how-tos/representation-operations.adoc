= Representation operations
:page-feature-status: experimental

For the common operations on representations, such as renaming, duplicating, or deleting them, refer to the https://doc.mbse-syson.org/syson/main/user-manual/hands-on/how-tos/representation-operations.html[SysON representation operations how-to].
This page describes the creation of Capella representations.

[#create-capella-representation]
== Create a Capella representation

A Capella representation can be created in two ways:

* From the xref:user-manual:features/editor.adoc[Capella project welcome area], displayed when no representation is open: the diagram is created on the default element of its perspective.
* From the explorer.
Open the context menu of a model element, select *New representation*, and choose the representation.
Only the representations applicable to the selected element are proposed.

The *New representation* dialog also proposes the SysON views applicable to the selected element, such as the General View.
The xref:user-manual:features/functional-context.adoc[Functional Context Diagram] can also be displayed without creating a representation, from the selection in the *Dynamic Contextual View* panel.

== Open an existing representation

Open a representation from the explorer, below the element it is created on, or from the list of existing representations in the Capella project welcome area.
