== Shared SysON operations

For common operations such as managing projects, navigating model elements, and working with representations, refer to the https://doc.mbse-syson.org/syson/main/user-manual/hands-on/hands-on.html[SysON How-Tos and Tutorials].

When creating a project for Arcadia modeling, choose the `Capella` or `Capella-Library` template as appropriate.
