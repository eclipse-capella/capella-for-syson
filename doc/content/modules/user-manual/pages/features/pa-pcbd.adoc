== Purpose

Describe the hierarchy of physical components.
It answers the question: How is the physical solution decomposed into components?

== Position in Arcadia

Physical Architecture.

== Main concepts

* *Behavior Physical Component*: A component carrying behavior in the physical architecture.
* *Node Physical Component*: A component providing a deployment resource.
* *Component containment*: The hierarchy of physical components.
