== Purpose

Describe capability realizations and the components involved in them.
It answers the question: How are capabilities realized by the solution architecture?

== Position in Arcadia

Capability realization viewpoint in the solution architecture.

== Main concepts

* *Capability Realization*: A capability as realized by the solution.
* *Component or Configuration Item*: A solution element involved in its realization.
* *Involvement*: The participation of a solution element in a realization.
