== Purpose

Describe the functional exchanges of the logical solution.
It answers the question: What flows between logical functions?

== Position in Arcadia

Logical Architecture.

== Main concepts

* *Logical Function*: A function of the logical architecture.
* *Function Port*: An exchange endpoint owned by a function.
* *Functional Exchange*: An exchange between logical functions.
* *Functional Chain*: A grouping of exchanges contributing to a logical behavior.
