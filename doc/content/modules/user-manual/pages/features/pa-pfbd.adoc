== Purpose

Decompose the functions of the physical architecture into a hierarchy.
It answers the question: How is the behavior of the physical solution organized?

== Position in Arcadia

Physical Architecture.

== Main concepts

* *Physical Function*: A function in the physical architecture.
* *Function containment*: The relationship organizing functions and sub-functions.
