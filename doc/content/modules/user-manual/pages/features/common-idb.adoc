== Purpose

Describe components and the interfaces through which they interact.
It answers the question: Which interface contracts connect the components?

== Position in Arcadia

Interface viewpoint shared across architecture descriptions.

== Main concepts

* *Component or Actor*: A participant using or providing an interface.
* *Component Port*: An endpoint on a participant.
* *Interface*: A contract connecting participants.
* *Interface use and implementation*: Relationships identifying the roles of the participants.
