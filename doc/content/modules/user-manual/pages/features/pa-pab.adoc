== Purpose

Describe the physical solution, including components, deployments, and connections.
It answers the question: How is the solution implemented and deployed?

== Position in Arcadia

Physical Architecture.

== Main concepts

* *Behavior Physical Component*: A component carrying functions of the physical solution.
* *Node Physical Component*: A resource on which behavior components are deployed.
* *Deployment*: The placement of behavior components on node components.
* *Physical Link and Path*: Connections and routes through the physical architecture.
