== Purpose

Describe exchanges between functions of the physical architecture.
It answers the question: What do the physical functions exchange?

== Position in Arcadia

Physical Architecture.

== Main concepts

* *Physical Function*: A function participating in the physical solution.
* *Function Port*: An input or output exchange endpoint.
* *Functional Exchange*: An exchange between physical functions.
* *Functional Chain*: A grouping of exchanges contributing to a behavior.
