== Purpose

Describe the hierarchical decomposition of logical components.
It answers the question: How is the logical solution organized into components?

== Position in Arcadia

Logical Architecture.

== Main concepts

* *Logical Component*: A building block of the logical solution.
* *Component containment*: The relationship between a component and its sub-components.
