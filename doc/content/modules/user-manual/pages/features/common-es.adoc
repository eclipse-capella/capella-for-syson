[NOTE]
====

== Purpose

Describe a scenario through the exchanges of components and actors.
It answers the question: How do architecture participants exchange information during this scenario?

== Position in Arcadia

Scenario viewpoint alongside an architecture description.

== Main concepts

* *Component or Actor lifeline*: An architecture participant in the scenario.
* *Exchange message*: An exchange between represented participants.
* *Message ordering*: The order of the interactions in the scenario.
