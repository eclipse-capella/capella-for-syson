== Purpose

Focus on one mission, the capabilities associated with it, and the actors involved.
It answers the question: Which capabilities and actors contribute to this mission?

== Position in Arcadia

System Analysis.

== Main concepts

* *Mission*: The purpose selected for examination.
* *Capability*: A capability contributing to the mission.
* *Actor*: An external participant involved in the context.
* *Capability exploitation*: The relationship associating a mission with a capability.
