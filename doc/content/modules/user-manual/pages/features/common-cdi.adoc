== Purpose

Focus on the detailed interface information of a component.
It answers the question: Which interfaces and ports define this component boundary?

== Position in Arcadia

Interface viewpoint, applied in the relevant architecture perspective.

== Main concepts

* *Component*: The component selected for examination.
* *Component Port*: An endpoint on the component boundary.
* *Interface*: A contract used or provided through the boundary.
* *Implementation and use relationships*: The component relationship to its interface contracts.
