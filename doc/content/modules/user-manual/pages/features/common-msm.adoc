== Purpose

Describe the modes and states of a system or component and the transitions between them.
It answers the question: How does behavior depend on the current mode or state?

== Position in Arcadia

Behavioral viewpoint, used alongside the relevant architecture perspective.

== Main concepts

* *Mode or State*: An operating mode or situation in the modeled behavior.
* *Transition*: A change between states or modes.
* *Region*: A container organizing part of the state machine.
* *Initial and final elements*: The entry and completion of a modeled behavior.
