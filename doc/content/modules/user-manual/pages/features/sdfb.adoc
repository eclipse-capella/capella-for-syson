== Purpose

Describe the functions of the system and its actors together with their functional exchanges.
It answers the question: What flows between the system functions?

== Position in Arcadia

System Analysis.

== Main concepts

* *System Function*: A function participating in the functional description.
* *Function Port*: An input or output endpoint of a Functional Exchange.
* *Functional Exchange*: Information, material, or energy exchanged between functions.
* *Functional Chain*: A grouping of exchanges and functions that contribute to a behavior.
