== Purpose

Describe the decomposition of the operational environment into entities and actors.
It answers the question: How are operational participants organized?

== Position in Arcadia

Operational Analysis.

== Main concepts

* *Operational Entity*: A participant that can contain other operational participants.
* *Operational Actor*: A human participant in the operational situation.
* *Containment*: The relationship organizing participants within a parent entity.
