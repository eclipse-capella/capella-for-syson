= {product} Overview

include::user-manual:partial$intro.adoc[]

Use Arcadia to organize the system description around operational needs, functions, components, and architectures.
SysML v2 provides the modeling language used to express these concepts and their relationships.

{product} runs in a web browser and is provided as an extension of SysON, a web-based SysML v2 modeling environment.
See xref:key-features.adoc[the key features] for the modeling environment and project templates, or the xref:installation-guide:index.adoc[installation guide] to set up the application.

If you already use Capella Desktop, the Arcadia engineering approach remains your methodological reference.
See xref:integration/capella.adoc[Capella Desktop and {product}] for the relationship between the tools and the role of the Capella SysML v2 Bridge.
