= Prerequisites

For server, database, browser, workstation, and network requirements, refer to the https://doc.mbse-syson.org/syson/main/installation-guide/requirements.html[SysON prerequisites].
Select the documentation corresponding to the SysON version you deploy.

== Capella for SysON extension

Use a Capella for SysON extension compatible with your SysON version.
The extension must be loaded and its frontend configured to provide the Capella modeling environment.
See xref:how-tos/install.adoc[the installation instructions].
